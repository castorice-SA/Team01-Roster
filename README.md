# ERAC 조사 1팀 인물 명단

조사 1팀의 세 인물을 한곳에서 순서대로 볼 수 있는 정적 GitHub Pages 사이트입니다.

1. 라이카 / 스칼릿 그레이스 — 팀장
2. 이름 미정 — 사라진 사람의 흔적을 좇는 전직 사냥꾼
3. 이름 미정 — 지도에서 사라진 구역에서 돌아온 전직 지도 제작자

각 카드에서 기존의 별도 인물 기록 홈페이지로 이동합니다. 두 신규 조사원의 이름과 실제 외형은 아직 확정되지 않았으므로 이 명단에도 미정으로 표시했습니다. 명단의 번호는 표시 순서이며 공식 사번이나 합류 시점을 뜻하지 않습니다.

이미지는 기존 개인 홈페이지에 사용한 자산입니다. `assets/laika.jpg`는 기존 라이카 삽화를 웹용으로 축소·변환했고, `assets/investigator-back.jpg`와 `assets/cartographer-back.jpg`는 해당 인물의 외형을 확정하지 않는 분위기 삽화입니다. `assets/erac-logo.png`는 기존 ERAC 문장입니다.
